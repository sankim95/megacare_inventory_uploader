## 2026-08-09 완료 작업

### 1. 단일 고득점 후보 자동 승인

- 유일 코드 정확 일치 또는 90점 이상 후보가 정확히 하나인 AI 추출 행을 자동 매칭
- `+재고`가 0 이상 정수인 자동 매칭 행만 승인으로 전환
- 90점 이상 후보가 둘 이상이거나 유효한 `+재고`가 없으면 보류 유지
- 수기 추가 행과 일반 편집 재계산에서는 기존 검수 상태를 자동 변경하지 않음

### 2. 사진별 보류 검수

- 검수 화면을 `보류 항목만 검수` 모드로 시작
- 보류 행이 있는 사진만 업로드 순서대로 표시하고 사진별 보류 개수 제공
- 현재 사진의 마지막 보류 행 처리 후 다음 보류 사진으로 자동 이동
- 토글 해제 시 승인·보류·제외를 포함한 전체 사진과 품목 확인

### 3. 보류 검수 바로가기와 원본 사진 확인

- 작업 전체 집계의 보류 수 클릭 시 보류 전용 모드와 첫 보류 사진의 추출 품목으로 이동
- 보정본 사진 보기 대신 업로드 원본 사진 보기를 제공하고 사진 클릭마다 시계 방향 90도 회전
- 후보의 `이 상품 선택·반영`으로 수동 매칭과 승인 의도를 한 번에 저장
- 유효한 `+재고`가 없으면 매칭은 보존하되 보류를 유지하고, 재고·단가 반영 체크는 변경하지 않음
- 작업 전체 집계의 상품명 클릭 시 스크롤 이동 없이 좌측 집계·우측 관련 행 편집의 분할 화면 제공
- 같은 상품의 여러 명세서 행은 우측 행 선택기로 전환하며, 1100px 이하에서는 세로 배치로 전환해 블록 겹침 방지

### 4. 보류 식별과 클릭 반응 개선

- 작업 전체 집계 위에 매칭·미매칭을 모두 포함한 보류 항목 바로가기 목록 제공
- 상품별 검수 상태 열과 보류 행 강조를 추가하고, 보류 항목 클릭 시 정확한 상품 행 또는 미매칭 원본 행으로 이동
- 상태와 재고·매입단가 반영 체크는 서버 응답을 기다리지 않고 먼저 화면에 반영
- 같은 행의 저장 queue·version과 실패 시 서버 최신값 복원은 유지하고, 집계 재조회는 저장 성공 뒤 백그라운드에서 수행

### 5. 작업 목록 삭제

- 작업 행의 `삭제` 버튼에서 인라인 확인 후 목록과 상단 집계를 즉시 갱신
- 초안·검수·실패·완료 작업의 연관 DB 데이터와 앱 소유 원본 Excel·이미지·결과 Excel 정리
- 추출·내보내기 중 작업은 UI에서 비활성화하고 서버에서도 409로 차단
- 삭제 실패 시 해당 작업 행을 유지하고 서버 오류 사유 표시

### 6. 새 작업 임시저장

- 새 작업 업로드 화면 진입 시 수행하던 즉시 작업 생성을 제거
- Excel과 사진 선택은 브라우저에만 유지하고 `임시저장`을 누를 때 작업을 한 번 생성
- 임시저장 시 작업 URL로 전환한 뒤 Excel을 검증·저장하고 사진을 원본 순서대로 저장
- 이미 저장된 작업의 파일 추가·교체와 AI 추출 이후 자동저장 흐름은 유지
- 저장 중 중복 클릭을 차단하고 일부 파일 저장 실패 시 생성된 작업과 재시도 가능한 선택 파일을 보존

### 7. 반복 매칭 학습과 사용자 직접 등록

- 사용자가 수동 확정한 OCR 코드와 상품명+규격 별칭을 실제 상품코드에 연결해 작업 간 재사용
- 다음 작업의 기준 Excel에 해당 상품코드가 있을 때만 저장된 매칭을 자동 적용하고 유효한 `+재고` 행 승인
- 수동 매칭 해제 시 해당 품목이 만든 연결을 함께 제거해 잘못된 학습을 교정
- 미매칭 화면에서 상품코드·상품명·규격·현재고·매입단가·공급사 정보를 직접 등록하고 즉시 매칭·반영
- 직접 등록 상품은 현재 작업에만 저장하고 내보낸 Excel 복사본의 새 행에 최종 재고·단가를 기록하며 원본 Excel은 보존
