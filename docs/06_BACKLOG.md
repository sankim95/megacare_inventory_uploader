## 현재 유지하는 정책

- 유일 코드 정확 일치 또는 90점 이상 후보가 정확히 하나이고 `+재고`가 유효한 AI 추출 행은 자동 승인하며, 나머지는 사진별 보류 검수에 남깁니다.
- 사용자가 확정한 OCR 별칭은 대상 상품코드가 다음 작업의 기준 Excel에 있을 때만 자동 재사용합니다. 신규 상품은 사용자 직접 등록으로만 현재 작업과 결과 복사본에 추가합니다.
- 음수 기존 `현재고`는 허용합니다. 이를 바꾸려면 반품·재고 정정 의미와 기존 데이터 이행을 포함한 별도 결정이 필요합니다.
- 음수 `매입단가`는 업로드에서 거절합니다.
- 소수점 매입단가는 원본 인덱스에 보존되지만 매칭 기준 단가로 사용되지 않습니다. BL-003 전에는 이 현재 동작을 확장하지 않습니다.
- 실제 OpenAI 호출을 하지 않은 상태에서는 자동 테스트 통과만으로 추출 품질 완료를 선언하지 않습니다.
